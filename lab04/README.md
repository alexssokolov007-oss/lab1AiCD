## Задание

Реализовать упорядоченное дерево для хранения пар «строковый ключ → вещественное значение».

- Ключ: непустая последовательность латинских букв, не более 6 символов
- Ключи упорядочиваются лексикографически
- Тип дерева: **(19 % 3) + 1 = 2 — B-дерево порядка n=2**

## Описание структуры

B-дерево порядка n=2:

| Параметр | Значение |
|---|---|
| Минимум ключей в не-корневом узле | 2 |
| Максимум ключей в узле | 4 |
| Максимум детей | 5 |

При вставке узел временно может содержать 5 ключей, после чего разбивается:
медиана (ключ с индексом 2) поднимается в родителя, оба потомка получают по 2 ключа.

Пример отображения дерева:

```
[dates:12.7|kiwi:3.7|mango:99.9|peach:6.2]
+-- [apple:1.5|berry:11]
+-- [fig:9.1|grape:5.9]
+-- [lemon:7|lime:8.4]
+-- [melon:13.3|olive:14.6]
\-- [pear:10.5|plum:4.1]
```

Каждый узел показан как `[ключ:значение|ключ:значение|...]`.

## Операции

| Номер | Формат | Описание |
|---|---|---|
| 1 | `1 <ключ> <значение>` | Добавить узел (или обновить значение) |
| 2 | `2 <ключ>` | Удалить узел |
| 3 | `3` | Напечатать дерево |
| 4 | `4 <ключ>` | Найти значение по ключу |

## Сборка и запуск

```bash
main.exe
```
