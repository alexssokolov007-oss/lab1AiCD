# Лабораторная работа №6 — Работа с файловой системой

**Вариант 19**

Рекурсивный обход указанного каталога и подкаталогов: подсчёт числа строк в каждом исходном файле (`*.h`, `*.cpp`) и вычисление суммарной длины (в строках).

---

## Теоретическая часть

### Подсчёт строк

Строка в текстовом файле — последовательность символов, заканчивающаяся символом `\n`. Программа считает количество символов `\n` в файле, что соответствует поведению утилиты `wc -l`.

### Рекурсивный обход каталога

На Windows обход выполняется через WinAPI: `FindFirstFileA` / `FindNextFileA` / `FindClose`. На каждой итерации проверяем, является ли текущий элемент каталогом — если да, рекурсивно обходим его; если нет, проверяем расширение файла.

На POSIX-системах используется `opendir` / `readdir` / `closedir` совместно с `stat` для определения типа файла.

---

## Описание программы

### Основные функции

| Функция | Описание |
|---------|----------|
| `count_lines(path)` | открывает файл и считает символы `\n`; возвращает `-1` при ошибке |
| `is_source(name)` | возвращает `1`, если имя файла оканчивается на `.h` или `.cpp` |
| `scan_dir(dir, total)` | рекурсивно обходит каталог, выводит каждый файл и его число строк, прибавляет к `*total`; возвращает количество найденных файлов |

## Примеры работы

### Пример 1 — сканирование проекта

Структура каталога:
```
project/
├── main.cpp       (3 строки)
├── util.h         (2 строки)
└── src/
    └── parser.cpp (5 строк)
```

Запуск:
```
./lab06 project
```

Вывод:
```
Каталог: project

     3  project\main.cpp
     2  project\util.h
     5  project\src\parser.cpp

Файлов:      3
Итого строк: 10
```

### Пример 2 — каталог без исходных файлов

```
./lab06 docs
```

```
Каталог: docs

Файлов:      0
Итого строк: 0
```

### Пример 3 — запуск без аргумента

Если аргумент не указан, сканируется текущий каталог:

```
./lab06
```

## Unit-тесты (GTest)

Тесты находятся в файле `tests.cpp`.

| № | Тест | Что проверяется |
|---|------|-----------------|
| 1 | `Lab6.EmptyFile` | пустой файл — результат 0 строк |
| 2 | `Lab6.MultipleLines` | файл с тремя строками — результат 3 |
| 3 | `Lab6.IsSource` | `.h` и `.cpp` → 1, `.c` и `Makefile` → 0 |
| 4 | `Lab6.ScanOneFile` | один `.h` в каталоге — правильный счётчик |
| 5 | `Lab6.ScanRecursive` | файлы в каталоге и подкаталоге суммируются |

## Сборка и запуск

```
make            — скомпилировать программу
make tests      — скомпилировать и собрать тесты (требуется GTest)
make run        — запустить на текущем каталоге
make clean      — удалить исполняемые файлы
```

Ручная сборка:
```bash
gcc -std=c11 -O2 -Wall -o lab06 main.c
./lab06 <каталог>
```

## Выводы

В ходе работы реализована программа, рекурсивно обходящая дерево каталогов и подсчитывающая строки во всех файлах с расширениями `.h` и `.cpp`. Для обхода используется Win32 API (`FindFirstFile`/`FindNextFile`) с POSIX-запасным вариантом через `opendir`/`readdir`. Строки считаются как число символов перевода строки `\n`, что является стандартным способом подсчёта строк в текстовых файлах.
