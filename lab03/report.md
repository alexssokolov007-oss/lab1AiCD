## Формулировка задания

Составить программу, которая читает арифметическое выражение, строит его дерево и выполняет преобразование: **вынести из частных унарные минусы**.

Правила преобразования для каждого узла деления:

| До | После |
|----|-------|
| `(-a) / b` | `-(a / b)` |
| `a / (-b)` | `-(a / b)` |
| `(-a) / (-b)` | `a / b` |

Два унарных минуса взаимно уничтожаются; нечётное количество выносится перед дробью.

## Описание выполненной работы

### Структура проекта

#### 1. `main.c` — дерево, парсер, преобразование, вывод

**Узлы дерева выражения:**

```c
typedef enum { NUM, VAR, NEG, ADD, SUB, MUL, DIV } NodeType;

typedef struct Node {
    NodeType type;
    int      num;
    char     var[32];
    struct Node *left;
    struct Node *right;
} Node;
```

**Парсер (рекурсивный спуск):**

Грамматика:
```
expr    = term  { ('+' | '-') term }
term    = unary { ('*' | '/') unary }
unary   = '-' unary | primary
primary = '(' expr ')' | number | variable
```

Парсер читает строку посимвольно и строит дерево. Бинарные операторы `+`, `-` — левоассоциативны; `*`, `/` — тоже левоассоциативны и имеют более высокий приоритет. Унарный минус создаёт узел `NEG`.

**Преобразование (вынос минусов из частных):**

```c
Node *transform(Node *n) {
    if (!n) return NULL;

    n->left  = transform(n->left);
    n->right = transform(n->right);

    if (n->type != DIV) return n;

    int negs = 0;

    if (n->left && n->left->type == NEG) {
        Node *child = n->left->left;
        n->left->left = NULL;
        free(n->left);
        n->left = child;
        negs++;
    }
    if (n->right && n->right->type == NEG) {
        Node *child = n->right->left;
        n->right->left = NULL;
        free(n->right);
        n->right = child;
        negs++;
    }

    if (negs % 2 == 1)
        return neg_node(n);

    return n;
}
```

Функция работает в порядке «снизу вверх» (сначала рекурсивно преобразуются поддеревья, затем текущий узел). Это гарантирует, что при цепочке делений преобразование применяется корректно на каждом уровне.

**Вывод (инфиксная нотация):**

Функция `print_node` выводит выражение с минимально необходимыми скобками, используя приоритеты операций. Унарный минус перед бинарным оператором оборачивает его в скобки: `-(a / b)`.

**Вывод (дерево):**

Функция `print_tree` выводит дерево в виде ASCII-графики:

```
/
+-- NEG(-)
|   \-- a
\-- b
```

#### 2. `tests.c` — юнит-тесты

Файл содержит 14 тестов, сгруппированных по сценариям:

- минус только в числителе: `(-a) / b → -(a / b)`
- минус только в знаменателе: `a / (-b) → -(a / b)`
- минусы в обоих операндах взаимоуничтожаются: `(-a) / (-b) → a / b`
- числовые константы под минусом
- выражения без изменений (нет минусов в делении)
- деление в контексте сложения и умножения
- составной числитель под минусом: `(-(a + b)) / c → -((a + b) / c)`
- минус внутри произведения **не** вытаскивается (не является прямым операндом деления)
- цепочки делений
