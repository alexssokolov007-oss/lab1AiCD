## Цель работы

Изучить представление графов в виде матрицы инцидентности и реализовать алгоритм нахождения кратчайших путей между всеми парами вершин (алгоритм Флойда-Уоршела).

---

## Теоретическая часть

### Матрица инцидентности

Для ориентированного взвешенного графа с `n` вершинами и `m` рёбрами матрица инцидентности `M` имеет размер `n × m`, где:

| Значение ячейки | Смысл |
|-----------------|-------|
| `+1` | вершина является **истоком** (началом) ребра |
| `-1` | вершина является **стоком** (концом) ребра |
| `0`  | вершина не инцидентна ребру |

Веса рёбер хранятся отдельно в массиве `w[m]`.

**Достоинства:** наглядное представление инцидентности, удобно для задач, связанных с рёбрами.  
**Недостатки:** расход памяти O(n·m), медленный поиск соседей O(m).

### Алгоритм Флойда-Уоршела

Находит кратчайшие расстояния между всеми парами вершин за O(n³).  
Основная идея: постепенно разрешать использование промежуточных вершин `k = 0, 1, ..., n-1`:

```
для k от 0 до n-1:
  для i от 0 до n-1:
    для j от 0 до n-1:
      если dist[i][k] + dist[k][j] < dist[i][j]:
        dist[i][j] = dist[i][k] + dist[k][j]
```

После выполнения алгоритма `dist[i][j]` содержит длину кратчайшего пути из `i` в `j`.  
Если `dist[i][i] < 0` для какой-либо вершины `i`, граф содержит **отрицательный цикл**.

## Описание программы

### Структуры данных

```c
typedef struct {
    int       *inc;  /* матрица инцидентности n_verts × n_edges */
    long long *w;    /* веса рёбер */
    int        nv;   /* число вершин */
    int        ne;   /* число рёбер */
} Graph;
```

### Основные функции

| Функция | Описание |
|---------|----------|
| `graph_new(nv, ne)` | выделяет память под граф с `nv` вершинами и `ne` рёбрами |
| `graph_read(f)` | читает граф из файла в формате списка рёбер |
| `graph_print_inc(g)` | выводит матрицу инцидентности в консоль |
| `build_dist(g)` | строит матрицу расстояний из матрицы инцидентности |
| `floyd_warshall(n, d)` | выполняет алгоритм Флойда-Уоршела |
| `has_neg_cycle(n, d)` | проверяет наличие отрицательного цикла |
| `print_dist(n, d)` | выводит матрицу кратчайших расстояний |
| `graph_free(g)` | освобождает память |

### Формат входного файла

```
n m
u1 v1 w1
u2 v2 w2
...
```

где `n` — число вершин, `m` — число рёбер; каждая строка описывает ориентированное ребро из вершины `u` в вершину `v` с весом `w`. Нумерация вершин с 0.

## Примеры работы

### Пример 1 (input.txt) — 5 вершин, 6 рёбер

**Входные данные:**
```
5 6
0 1 1
0 2 5
1 2 2
1 3 3
2 4 1
3 4 4
```

**Вывод программы:**
```
Матрица инцидентности (5 x 6):
     e0   e1   e2   e3   e4   e5
v0    +1   +1    0    0    0    0
v1    -1    0   +1   +1    0    0
v2     0   -1   -1    0   +1    0
v3     0    0    0   -1    0   +1
v4     0    0    0    0   -1   -1
Веса рёбер: e0=1, e1=5, e2=2, e3=3, e4=1, e5=4

Матрица кратчайших расстояний (алгоритм Флойда-Уоршела):
0 1 3 4 4
INF 0 2 3 3
INF INF 0 INF 1
INF INF INF 0 4
INF INF INF INF 0
```

**Пояснение:** путь `0→2` = 3 (через вершину 1: 1+2), хотя есть прямое ребро 0→2 весом 5.

### Пример 2 (input_small.txt) — 4 вершины, 5 рёбер

**Входные данные:**
```
4 5
0 1 5
0 2 10
1 2 3
1 3 8
2 3 2
```

**Вывод:**
```
Матрица кратчайших расстояний (алгоритм Флойда-Уоршела):
0 5 8 10
INF 0 3 5
INF INF 0 2
INF INF INF 0
```

### Пример 3 — граф с отрицательным циклом

Ребра: 0→1(1), 1→2(−3), 2→0(−3). Сумма цикла = −5.

**Вывод:**
```
В графе обнаружен отрицательный цикл!
```

## Unit-тесты (GTest)

Тесты находятся в файле `tests.cpp` и покрывают 5 сценариев:

| № | Тест | Что проверяется |
|---|------|-----------------|
| 1 | `IncMatrix.BuildDistBasic` | корректное заполнение матрицы расстояний из матрицы инцидентности |
| 2 | `FloydWarshall.ChainRelaxation` | нахождение пути через промежуточную вершину |
| 3 | `FloydWarshall.ShortcutPreferred` | выбор более короткого из двух альтернативных путей |
| 4 | `FloydWarshall.NoPath` | INF для вершин из несвязных компонент |
| 5 | `FloydWarshall.NegCycleDetected` | обнаружение отрицательного цикла |

## Выводы

В ходе работы были реализованы:
- представление ориентированного взвешенного графа в виде **матрицы инцидентности**;
- преобразование матрицы инцидентности в матрицу расстояний;
- алгоритм **Флойда-Уоршела** для поиска кратчайших путей между всеми парами вершин;
- обнаружение отрицательных циклов.

Сложность алгоритма — O(n³) по времени, O(n²) по памяти. Матрица инцидентности наглядно отражает структуру графа, однако занимает O(n·m) памяти, что при плотных графах хуже матрицы смежности.
