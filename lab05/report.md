# Лабораторная работа №5
## Алгоритмы на графах

**Вариант:** 19  
**Представление графа:** (19 % 3) + 1 = **2 — Матрица инцидентности**

## 1. Описание задачи

Требуется:
1. Реализовать хранение взвешенного ориентированного графа в виде **матрицы инцидентности**.
2. Реализовать алгоритм нахождения кратчайших путей между всеми парами вершин — **алгоритм Флойда–Уоршелла**.
3. Покрыть реализацию модульными тестами (GTest) и провести замеры производительности.

---

## 2. Структура данных — Матрица инцидентности

### Определение

Для ориентированного графа с **n** вершинами и **m** рёбрами матрица инцидентности
B имеет размер **n × m**, где:

| B[i][j] | Смысл |
|---------|-------|
| **+1** | вершина i является **хвостом** (источником) ребра j |
| **−1** | вершина i является **головой** (стоком) ребра j |
| **0**  | вершина i не инцидентна ребру j |

Вес каждого ребра хранится в отдельном массиве `weights[j]`.

### Пример

Граф: 0→1 (w=3), 0→2 (w=6), 1→2 (w=2), 2→3 (w=1)

```
     e0   e1   e2   e3
v0  [ 1    1    0    0 ]
v1  [-1    0    1    0 ]
v2  [ 0   -1   -1    1 ]
v3  [ 0    0    0   -1 ]
weights: [3, 6, 2, 1]
```

### Сложность

| Операция | Сложность |
|----------|-----------|
| Добавление ребра | O(n) — дописывается столбец |
| Построение матрицы смежности | O(n·m) |
| Хранение | O(n·m) |

## 3. Алгоритм Флойда–Уоршелла

### Идея

Алгоритм динамического программирования. Обозначим `dist[i][j]` — длина
кратчайшего пути из i в j, рассматривая только промежуточные вершины
из множества {0, 1, …, k}.

**Рекуррентное соотношение:**

```
dist[i][j] = min( dist[i][j],  dist[i][k] + dist[k][j] )
```

Перебираем k от 0 до n−1.

### Инициализация

```
dist[i][j] = weight(i→j)  если ребро существует
dist[i][j] = 0             если i == j
dist[i][j] = ∞             иначе
```

### Восстановление пути

Матрица `next[i][j]` = первая вершина после i на кратчайшем пути к j.
При обновлении: `next[i][j] = next[i][k]`.

### Обнаружение отрицательного цикла

После завершения алгоритма: если `dist[i][i] < 0` для любой i —
в графе есть отрицательный цикл.

### Псевдокод

```
for k = 0..n-1:
    for i = 0..n-1:
        for j = 0..n-1:
            if dist[i][k] + dist[k][j] < dist[i][j]:
                dist[i][j] = dist[i][k] + dist[k][j]
                next[i][j] = next[i][k]
```

### Сложность

| | |
|--|--|
| **Время** | O(V³) |
| **Память** | O(V²) |

## 4. Модульные тесты (GTest)

Написано **5 тестов** в файле `tests/test_graph.cpp`:

| # | Имя теста | Что проверяется |
|---|-----------|-----------------|
| 1 | `BasicShortestDistances` | Корректность расстояний в простом ориентированном графе |
| 2 | `DisconnectedVertices` | Несвязные вершины — расстояние равно ∞ |
| 3 | `NegativeEdgeWeights` | Корректная работа при отрицательных весах (без цикла) |
| 4 | `NegativeCycleDetected` | Обнаружение отрицательного цикла |
| 5 | `PathReconstruction` | Восстановление кратчайшего пути |

Запуск тестов:
```
cmake -B build
cmake --build build
cd build && ctest --output-on-failure
```

Теоретическая сложность алгоритма — O(V³). Это означает, что при
удвоении числа вершин время должно вырасти примерно в 8 раз.

теоретической оценки (основной вклад вносит шаг O(V³), а не
построение матрицы смежности O(n·m)).

## 7. Выводы

- Матрица инцидентности — гибкое представление, позволяющее хранить
  параллельные рёбра; недостаток — O(n·m) памяти против O(n²) для
  матрицы смежности.
- Алгоритм Флойда–Уоршелла за O(V³) находит кратчайшие пути между
  всеми парами вершин и корректно обнаруживает отрицательные циклы.
- При V = 1000 алгоритм выполняется за порядка единиц секунд на
  современном ПК, что приемлемо для задач умеренного размера.
